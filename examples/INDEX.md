# Example Index

This file used to hand-catalog every example (chapter, title,
role/motion/groove tags, difficulty) for the book's earlier
single-voice, bass-only edition, one row per chapter, linking into
`by-chapter/`. At today's scale — over 160 canonical grand-staff files
across 40 chapters — a hand-maintained duplicate catalog like that one
goes stale the moment a chapter changes, and nothing validates it, so
it did: most of its rows described chapters that have since been
fully rewritten under different titles and terms.

There's no single flat index of every example anymore, by design.
Instead:

- **To find a chapter's examples**, go to the chapter itself
  (`book/part-*/`) — every chapter embeds its own Microscope
  (`## The Microscope`), exercise (`## Play`), and study
  (`## The Music`) inline, byte-identical to the standalone files
  under `examples/laboratories/`, `examples/exercises/`, and
  `examples/studies/`.
- **To find every complete study**, see
  [`../publish/studies.qmd`](../publish/studies.qmd) — the
  reader-facing catalog of all 40 studies plus the closing capstone,
  each linked back to its chapter.
- **To find a term's chapter number**, see
  [`../docs/glossary.md`](../docs/glossary.md) or
  [`../docs/chapter-map.md`](../docs/chapter-map.md).
- **To find the file-naming and directory conventions** a new example
  should follow, see
  [`../docs/notation-conventions.md`](../docs/notation-conventions.md).
