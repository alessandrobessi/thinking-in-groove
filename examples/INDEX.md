# Example Index

Every chapter's example is a short (3-4 bar, occasionally longer)
variation on one fixed laboratory progression, in the style of the
companion project [Thinking in Layers](https://github.com/alessandrobessi/thinking-in-layers)
— see [`_lab/laboratory.abc`](_lab/laboratory.abc) for the shared
baseline every row below varies from, and `docs/notation-conventions.md`
for the convention.
